# Building a time series forecasting assistant with Amazon Bedrock and LibreChat

A conversational time series forecasting assistant that allows the user to retrieve time series data from ClickHouse and generate time series forecasts using Chronos on Amazon Bedrock through the LibreChat UI. Claude Sonnet 4.6 on Amazon Bedrock orchestrates the MCP tools and explains the results in natural language.

Full details in the [blog post](https://flaviagiammarino.com/blog/chronos_bedrock.html).
